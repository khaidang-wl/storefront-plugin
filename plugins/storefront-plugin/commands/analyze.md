# Analyze Command

Analyze the selected code or the file specified in $ARGUMENTS for:

1. **Code Quality**: Look for potential bugs, edge cases, and logic errors
2. **Performance**: Identify performance bottlenecks or inefficient patterns
3. **Best Practices**: Check adherence to language-specific best practices
4. **Security**: Look for common security vulnerabilities
5. **Readability**: Suggest improvements for code clarity and maintainability

Provide specific, actionable suggestions with code examples where helpful. Be concise and prioritize the most important issues.
